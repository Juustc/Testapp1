Billet DEMO — maquette pour jeu vidéo

Contenu :
- index.html : application
- manifest.json : installation comme web-app
- sw.js : cache hors connexion
- icon-192.png / icon-512.png : icônes

Fonctions :
- Horloge HH:MM:SS en temps réel
- Import d'une image + recadrage carré tactile + zoom
- Textes modifiables en touchant chaque champ
- Sauvegarde locale sur l'appareil
- Mode PWA / écran d'accueil
- Marquage permanent DEMO / NON VALABLE

Pour l'utiliser sur iPhone :
1. Héberger ce dossier sur un service HTTPS (par ex. GitHub Pages).
2. Ouvrir l'adresse dans Safari.
3. Partager > Sur l'écran d'accueil > Ouvrir comme app web.
